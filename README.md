# 喵野求生 · GitHub Pages 发布包

这个文件夹可以直接作为 GitHub 仓库的根目录发布。`index.html` 包含游戏所需的全部程序、样式、像素画与音效，无需构建、后端服务器或安装依赖。

## 发布到 GitHub Pages

1. 登录 GitHub，建立名为 `cat-survival` 的 **Public** 空仓库。
2. 上传本目录内的 `index.html` 和 `README.md` 到仓库根目录，并提交。
3. 打开仓库的 **Settings → Pages**，在 **Build and deployment** 里选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/(root)` 目录，保存，等待 Pages 发布。
5. 发布地址的格式为 `https://你的用户名.github.io/cat-survival/`；用这个公开 HTTPS 地址分享给朋友。

首次上传的内容公开可读。朋友打开网页可以立即试玩，不需要登录 GitHub，也无需在自己的电脑上搭建服务器。本目录的游戏进度保存在各自浏览器，没有账号或云端同步。
